📊 DataManagementP47 — SQL, Dapper & EF Core Comparison
Цей проєкт — це практичне порівняння трьох поколінь роботи з даними в .NET. Кожен модуль показує, як одна й та сама задача вирішується різними інструментами.

🏛️ Основні модулі проєкту

📁 Клас Ado.cs — Робота через ADO.NET
Це "ручне" керування базою за допомогою чистих SQL-запитів.
Керування структурою: Створення таблиць та розгортання схеми безпосередньо через SqlCommand.
Генерація: Створення 1000 записів про продажі з випадковими параметрами.
Статистика: Обчислення агрегованих даних (кількість, середній чек) через ExecuteScalar.
Безпека: Обов'язкове використання параметрів для захисту від SQL-ін'єкцій.

📁 Клас DapperAccessor.cs — Робота через Dapper ORM
Використання "мікро-ORM" для миттєвого перетворення SQL-результатів у об'єкти C#.
Автомапінг: Отримання списків товарів чи співробітників одним рядком коду без SqlDataReader.
Випадковий вибір: Логіка ORDER BY NEWID() для динамічного отримання записів прямо з БД.
Синтаксис: Використання сучасних виразів та анонімних типів для передачі параметрів.

📁 Клас EfDemo.cs — Практика Entity Framework Core
Демонстрація повного ORM-підходу, де замість SQL використовуються LINQ-запити.
Масштаб: Генерація 10,000 записів про продажі з автоматичним відстеженням зв'язків.
LINQ-аналітика: Розрахунок статистики за допомогою вбудованих методів .Min(), .Max() та .Average().
Join-запити: Поєднання даних з декількох таблиць (Товар + Продавець + Фірма) у складні об'єкти.

📁 Клас EfSearchHW.cs — Пошуковий сервіс (Home Work)
Інтерактивний інструмент для гнучкої фільтрації даних у базі.
Пошук за ім'ям: Використання .Contains() для знаходження збігів у тексті.
Розрахунок віку: Складний алгоритм обчислення повних років на основі дати народження.
Гібридна обробка: Використання .AsEnumerable() для виконання обчислень на стороні C#, які неможливо транслювати в SQL.
